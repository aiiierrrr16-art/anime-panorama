# ANIME PANORAMA

日本知名动漫全景目录：按年代、类型与影响力整理 393 部／系列，并提供个人“看过”记录、组合筛选和资料检索。

## 在线访问

[anime-panorama-archive.aierer.chatgpt.site](https://anime-panorama-archive.aierer.chatgpt.site)

## 主要功能

- 1963—2026 日本动画目录
- 作品名、类型与入选理由搜索
- 年代、类型、影响力等级筛选
- “全部／未看／已看”观看状态筛选
- 浏览器本地保存观看记录
- 每部作品的 Google 百科资料入口
- 响应式新粗野主义界面

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 数据

目录数据位于 `public/anime.json`。当前版本包含 393 条记录。
